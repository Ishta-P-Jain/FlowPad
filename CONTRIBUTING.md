# Contributing to FlowPad

Thank you for your interest in contributing to FlowPad!

We welcome contributions from developers, designers, students and open-source enthusiasts.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a new branch for your changes.
4. Install the required dependencies.
5. Work on an existing issue or propose a new feature.
6. Test your changes.
7. Submit a pull request.

## Branch Naming

Use descriptive branch names:

- `feat/floating-notes`
- `feat/markdown-editor`
- `fix/autosave`
- `docs/setup-guide`

## Pull Request Guidelines

- Keep changes focused.
- Follow the existing project structure.
- Write clear commit messages.
- Test your changes before submitting.
- Include screenshots for UI changes where possible.
- Link the related GitHub issue.

## Code of Conduct

Be respectful, collaborative and welcoming.

Constructive feedback and beginner-friendly discussions are encouraged.

Thank you for helping build FlowPad!
