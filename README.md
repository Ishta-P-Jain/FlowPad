# FlowPad

### Your thoughts. Your workflow. One floating workspace.

FlowPad is an open-source floating note-taking workspace designed for students, developers and online learners.

It allows users to create and edit notes directly alongside the webpages they are browsing, without constantly switching between applications.

## Why FlowPad?

Taking notes while watching lectures, following coding tutorials or reading documentation often requires switching between multiple windows.

FlowPad aims to make this experience simpler by providing an accessible floating notes interface inside the browser.

## Features

### Chrome Extension

- Quick access through a keyboard shortcut.
- Floating and draggable notes panel.
- Create, edit and organize notes.
- Automatic local saving.
- Rich-text and Markdown editing.
- Screenshot attachments.
- Webpage URL and YouTube timestamp capture.

### Web Dashboard

- View and manage saved notes.
- Organize notes into folders.
- Search and filter notes.
- Import and export notes.
- Optional cloud synchronization.

## Technology Stack

- React.js
- JavaScript
- Tailwind CSS
- Chrome Extension Manifest V3
- Chrome Storage API
- IndexedDB
- Supabase (planned)

## Project Status

Currently in initial development.

The first milestone focuses on building the Chrome extension, floating notes interface and local note persistence.
